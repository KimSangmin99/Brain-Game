# BRAINLAB 첫 화면 디자인 방향 검토

2026-11-09 · 세 방향 비교 기록. 사용자가 A ‘오늘의 한 걸음’을 선택했으며 앱에 적용했다. 아래 시안과 설명은 선택 당시 비교 자료다. 시안은 정적 예시이고 실제 구현은 src에 있다. 실제 배포 상태는 개발 진행 기록을 따른다.

## 사용자와 작업

성인 일반 사용자와 중장년·시니어가 주 대상이다. 첫 화면은 (1) 최근 게임을 빠르게 시작하기, (2) 다른 게임 찾기, (3) 학습 전략과 같은 조건의 기록 돌아보기를 지원한다. 세 시안은 같은 재방문자 예시(패턴 4단계·시퀀스 2단계 완료, 다음 패턴 5단계)를 기준으로 비교한다. 기록은 모두 목업 데이터다. 게임 점수를 지능·건강 진단으로 환산하지 않는다.

## 세 방향

| 항목 | A. 오늘의 한 걸음 | B. 나의 학습 노트 | C. 생각의 탐사선 |
| --- | --- | --- | --- |
| 우선 사용자·작업 | 첫 이용·시니어, 무엇을 할지 고민 없이 시작 | 재방문·자기주도 학습, 진도·전략·기록 비교 | 게임 탐색을 즐기는 사용자, 호기심으로 게임 발견 |
| 배치 | 상단 탐색 → 단일 주 행동 → 학습 3단계 → 게임 2개 | 좌측 탐색 → 수치 요약 → 진도 행+전략 노트 → 기록 표 | 상단 탐색 → 공간 지도 → 떠 있는 이어하기 패널 → 탐사 요약 |
| 정보 밀도 | 낮음. 한 화면에서 가장 중요한 행동을 크게 강조 | 높음. 카드 나열 대신 행·구분선·표로 비교 | 중간 이하. 정보보다 공간·탐색 관계를 강조 |
| PC 글자 위계 | 제목 46px / 주 설명 19px / 게임 제목 18px | 제목 33px / 게임 제목 19px / 설명 13~14px / 표 12px | 제목 35px / 미션 제목 23px / 미션 설명 13px |
| 모바일 제목 | 34px | 28px | 31px |
| 이미지 방식 | 기억 보드를 종이 오브젝트처럼 표현한 단일 SVG | 장식 이미지 없음. 진도 선·서체·표가 중심 | 화면 전체의 궤도·도형 행성 SVG, 분야를 공간으로 표현 |
| 장점 | 읽기·첫 시작·접근성이 가장 명확 | 같은 화면에서 이어하기·학습·회고 가능 | 게임으로서의 정체성과 탐색 동기가 가장 강함 |
| 고려할 점 | 전체 게임을 펼쳐 보는 데 한 번 더 이동 | 작은 글자가 많아 시니어에는 큰 글자·간소화 모드 필요 | 모바일은 목록 전환과 큰 조작 영역이 필요하며 분야 간 선행 잠금으로 오해하지 않게 설명 |

추천은 A다. 대상 연령이 넓고 게임과 학습 도구를 함께 지향하므로 시작하기와 가독성을 우선한다. 이는 사용성 검증 전 디자인 판단이며 실제 사용자 테스트 결과는 아니다. 미래 연구소라는 기존 세계관을 강하게 유지하는 선택은 C다.

## 현재 디자인 기준과 선택의 관계

- `docs/planning/product-plan.md`: 성인·중장년·시니어, 미래적인 연구소, 게스트 체험과 게임별 독립 진행.
- `docs/planning/screen-flows.md`: 남색 배경, 기본 글자 18px, PC 상단·모바일 하단 탐색, 본문 폭 1120px와 조작 영역 44px 이상.
- 실제 구현은 자체 CSS와 Lucide 아이콘, Next.js·React다. 외부 구매 템플릿이나 고정된 UI 키트는 확인되지 않았다. AGENTS.md는 Next.js 문서를 먼저 읽도록 하며 특정 디자인을 강제하지 않는다.
- 이번 사용자의 요청에 따라 기존 배경·탐색 배치·글자 위계는 변경 가능한 항목으로 비교했다. 선택 후 해당 디자인 기준 문서를 함께 갱신한다. A/B는 기존 남색 연구소 표현을 변경하며 B는 기본 18px 지침도 재검토해야 한다.
- 모든 방향에서 큰 조작 영역, 키보드 접근, 색만으로 정답을 구분하지 않기, 게임별 독립 진행을 유지한다. 시안의 버튼은 최소 높이 44px이다. 전체 대비·확대·스크린리더 검증은 선택 후 실제 구현에서 수행한다.
- C의 지도는 게임을 강제로 순서대로 깨는 공통 스테이지 맵이 아니다. 기억·추론·논리·주의는 분야 입구이고 게임별 진행은 독립이다. 현재 준비 중인 6종을 이미 출시한 것처럼 표현하지 않는다.

## 파일과 확인

- `index.html`: 외부 파일 없이 열리는 독립 HTML. 상단 A/B/C 비교 탭만 동작한다. 게임·계정 버튼은 화면 배치 검토를 위한 정적 요소다.
- `a-desktop.png`, `b-desktop.png`, `c-desktop.png`: 1200×840 첫 화면.
- `a-mobile.png`, `b-mobile.png`, `c-mobile.png`: 390×844 첫 화면. 아래 내용은 스크롤된다.
- `render.mjs`: 프로젝트에 설치된 Playwright로 이미지를 재생성한다. 파일 URL이 차단된 환경도 지원하도록 HTML을 직접 로드한다.

```sh
node design-explorations/2026-11-09/render.mjs
```

PC·모바일 6개 화면의 가로 넘침 없음과 비교 탭 전환을 확인했다. 일러스트는 자체 SVG이며 외부 이미지·폰트 다운로드를 사용하지 않았다.

## 선택 후 구현 범위

선택한 방향으로 홈, 게임 목록·상세, 조작 안내·플레이·결과·해설, 기록, 계정·로그인·가입, 준비 중인 챌린지와 오류·빈 상태를 통일한다. 기존 판정·저장·인증 동작을 유지하고 PC·모바일·큰 글자·키보드와 실제 콘텐츠 밀도를 검증한다. 선택 전에는 제품 화면에 적용하지 않는다.
