# A 디자인 · 오늘의 한 걸음

사용자 선택: 2026-11-09. 성인 일반 사용자와 중장년·시니어가 게임을 쉽게 시작하고, 전략을 이해하고, 기록을 돌아보도록 한다. 세 방향 비교는 [시안 기록](../design-explorations/2026-11-09/README.md)에 보존한다.

## 시각 언어

| 역할 | 기준 |
| --- | --- |
| 바탕 | 밝은 아이보리 #f7f7f0 |
| 패널 | 따뜻한 흰색 #fffefa |
| 본문 | 짙은 녹색 #253b2e |
| 주 행동 | 녹색 #355b43 + 흰색 글자 |
| 보조 설명 | #596a55 |
| 보조 패널 | #edf1e6 |

| 이미지 | 홈의 기억 보드 SVG 1개. 실물 종이처럼 겹친 면·부드러운 그림자. 반복 애니메이션이나 정답 정보 없음 |

## 글자와 조작

- 기본 본문 18px, 보조 설명 16px. 게임 목표·지시·폼 입력은 본문 크기를 유지한다.
- 홈 제목 PC 48px, 모바일 32~35px. 일반 페이지 제목 32~44px, 플레이 지시 25~32px, 게임명 21~23px.
- 작은 메타 정보는 13~14px. 핵심 지시나 버튼을 메타 크기로 축소하지 않는다.
- 큰 글자 설정은 본문 21px·보조 19px로 늘리고, 작은 화면에서는 장식을 숨기거나 카드를 재배치한다. 저장 공간이 허용하면 선택을 유지한다.
- 일반 버튼 48~60px, 폼 입력 56px, 게임 셀 최소 44px. 링크와 버튼의 키보드 포커스는 황갈색 3px 외곽선이다.
- 레이아웃은 고정 높이로 문장을 자르지 않는다. 브라우저 확대·좁은 화면에서 줄바꿈과 세로 스크롤을 허용한다.

## 화면별 배치

| 화면 | 배치와 주 행동 |
| --- | --- |
| 홈 | 인사·실제 완료 단계 → 큰 시작/이어하기 1개+작은 오브젝트 → 학습 3단계 → 이어할 게임 외 다른 2게임. 전체 8종은 별도 링크 |
| 전체 게임 | 분야 필터와 가로형 카드. PC 2열·모바일 1열. 목표·준비 상태·개별 완료 수 |
| 상세 | 목표·주 시작 버튼을 먼저, 이후 단계 목록과 자유 연습. 단계는 PC 3열·작은 모바일 1열 |
| 플레이·안내 | PC 문제와 전략 2열, 모바일은 문제 다음 전략. 공통 탐색과 푸터는 접고 나가기·단계·저장 상태 유지 |
| 피드백·결과 | 지시 위계 유지, 체크·×와 설명, 다음 행동 1개+기록 보기. 통과/도움/중단은 색 외 텍스트로도 표시. 결과에서 공통 탐색 복원 |
| 기록 | 결과별 가로 행과 도움 태그, 복습 입구. 좁은 화면에서는 점수·복습을 다음 행으로 배치 |
| 계정·인증 | 한 열의 따뜻한 흰색 폼. 라벨·설명을 붙이고 오류는 입력 근처에 유지. 실제 저장 상태와 계정/게스트 기록을 구분 |
| 준비·오류·빈 상태 | 한 문장 설명과 가능한 다음 행동. 미구현 기능·통계·사용자 데이터를 꾸며 표시하지 않음 |

## 구현 위치와 변경 경계

- `src/app/globals.css`: 색·크기 토큰, 모든 화면 컴포넌트, 반응형·큰 글자·동작 감소.
- `src/components/shell.tsx`: 공통 탐색, 계정, 글자 설정, 플레이 집중 모드.
- `src/components/lab.tsx`: 홈 재구성, 게임 목록, 상세·기록·준비 화면.
- `src/components/memory-illustration.tsx`: 홈 전용 SVG.
- 기존 게임 상태·판정·제시 시간·저장·회원 API는 유지한다. 디자인을 위한 운영 DB 변경은 없다.

## 확인 방법

`npm run test:e2e`는 게임 완료·복구·계정 병합·기록 동기화 외에 큰 글자 선택 유지, Escape 닫기·포커스 복귀, 플레이 탐색 숨김·나간 뒤 복원을 검사한다.

`design-explorations/2026-11-09/audit-implementation.mjs`는 실행 중인 앱에서 PC·태블릿·모바일·큰 글자 화면을 캡처하고 가로 넘침·버튼 크기·브라우저 오류를 확인한다. 결과는 같은 폴더의 `implemented/`에 저장한다. 기본 주소는 localhost:3100이고 DESIGN_A_BASE_URL로 변경할 수 있다. 기록이 채워진 결과 캡처는 로컬 게스트 예시 플레이이며 실제 사용자의 데이터가 아니다. 실기기·실제 시니어 사용자 검증을 대신하지 않는다.

규칙 분석은 단서·허용 규칙·4개 선택지·문항 해설을 같은 색·글자 위계로 제공한다. PC에서는 단서를 보며 선택지를 비교할 수 있게 배치하고, 모바일 큰 글자에서는 선택지를 1열로 둔다.

코드 브레이커는 작성 중 코드 → 기호 팔레트 → 추측 전체와 두 단서를 세로로 배치한다. 5자리 입력은 360px 큰 글자에서도 최소 44px 조작 폭을 유지하고 모바일 팔레트는 3열이다. 색·모양·기호 이름을 함께 사용하고 정답은 도전 종료 후 공개한다.
