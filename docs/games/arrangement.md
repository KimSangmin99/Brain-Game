# 조건 배열 · arrangement-v1

2026-11-12. 다섯 번째 게임이자 첫 논리 게임이다. 여러 위치·관계 조건을 읽고 모든 대상을 한 번씩 배치한다. 일반 스테이지와 자유 연습을 제공하며 응답 시간 제한은 없다.

화면 예시: [PC](arrangement-desktop.png) · [360px 큰 글자·6명](arrangement-mobile.png). 실제 회원 자료가 아닌 로컬 테스트 기록이다.

## 진행과 조작

안내 → 조작 예제 → 배열 퍼즐 하나 → 조건 확인 → 결과와 풀이로 이어진다. 구간 첫 단계인 1·6·11·16·21·26단계는 예제의 모든 조건을 만족해야 시작할 수 있다. 예제와 본문제는 서로 다른 문제이며 예제 오류는 본 도전의 점수·도움 상태에 반영하지 않는다.

대상을 선택하고 자리를 누르면 배치한다. 놓인 대상을 옮기거나 이미 채워진 두 자리를 교환할 수 있다. 대기 중인 대상을 채워진 자리에 놓으면 기존 대상은 대기로 돌아간다. 마우스 드래그도 지원하며 터치·키보드에서는 선택 후 배치로 같은 작업을 수행한다.

숫자 1~6으로 대상 선택, Tab으로 자리 이동, 자리에서 Enter/Space로 배치한다. 자리의 좌우 방향키로 포커스를 옮기고 Delete/Backspace로 비운다. 전체 비우기도 제공한다. 왼쪽에서 오른쪽 순서의 자리 번호를 한 줄로 유지하며, 대상은 이름·모양·색으로 구분한다. 360px 큰 글자에서 6자리의 최소 조작 폭은 44px다.

편집 중에는 조건의 정오를 표시하지 않으며 옮기거나 비우는 횟수에 점수 불이익이 없다. 모든 대상이 서로 다른 자리에 한 번씩 놓여야 확정할 수 있다.

## 30단계와 조건의 뜻

| 단계 | 대상 | 조건 |
| --- | --- | --- |
| 1~5 | 3명 | 직접 지정한 위치 |
| 6~10 | 3명 | 직접 위치 + 바로 왼쪽 |
| 11~15 | 4명 | 왼쪽·오른쪽 순서 |
| 16~20 | 4명 | 순서 + 양쪽 방향의 인접 |
| 21~25 | 5명 | 순서 + 특정 자리 아님 |
| 26~30 | 6명 | 직접 위치·순서·바로 왼쪽·인접·부정 조건 혼합 |

‘왼쪽’은 번호가 더 작은 자리이며 중간에 다른 대상이 있어도 된다. ‘바로 왼쪽’은 번호 차이가 1이고 첫 대상이 왼쪽이어야 한다. ‘바로 이웃’은 번호 차이가 1이며 양쪽 방향을 모두 허용한다. ‘아님’은 지정한 한 자리만 제외한다. 각 단계에는 도입·적용·혼동 구분·변형·종합에 맞는 목표 문구를 제공한다.

## 문제 검수와 유일성

- 각 단계의 정해진 조건 틀을 최대 6! = 720개 배치 전체와 대조해 유일한 해를 확인한다. 대상 이름을 치환한 은행에서 무작위 선택하며, 해가 없는 문제·복수 정답인 생성 문제는 제공하지 않는다.
- 단서 수는 대상 수 이상이다. 16~20단계는 인접 조건을 모두 빼면 여러 해가 남는다. 21~30단계는 다른 조건 모두를 만족하는 교환 배치가 부정 조건에 의해 제외되도록 구성해 새 조건이 필요하게 만든다.
- 일반 판정 함수는 특정 정답 배열과 비교하지 않고 모든 술어의 충족 여부로 판정한다. 복수 해답을 허용하는 검증 예시에서도 모든 유효 배치를 정답으로 인정한다. 현재 서비스 문제 은행은 유일한 해만 사용한다.
- 예제의 문제 ID는 본문항에서 제외하고 재도전은 직전 문제도 제외한다. 단계의 은행 규모는 3명 6개·4명 24개·5명 120개·6명 720개이며 예제 제외 후 제공한다. 장기 노출 이력을 이용한 반복 표시·복습 추천은 후속 범위다.
- `arrangement-v1` / `arrangement-content-v1`로 규칙과 콘텐츠를 구분한다. 서버는 문제 ID뿐 아니라 해당 단계 은행의 실제 조건 내용·순서도 검증한다.

## 틀린 제출·도움·점수

틀리면 완료로 처리하지 않고 제출한 배치를 잠시 고정해 조건별 만족/다시 확인과 실제 자리 번호를 설명한다. ‘배치 수정하기’를 누르면 같은 배치에서 고칠 수 있다. 이 구체적인 피드백을 본 도전은 도움 사용으로 기록한다. 중복 확정은 피드백·결과 상태에서 무시한다.

모든 조건을 만족한 해결은 첫 제출과 수정 후 모두 10,000점이다. 수정 후 해결·힌트 사용·중단이 있는 경우 독립 해결과 구분한다. 건너뛰기·풀이 열람은 0점이며 다음 단계를 열지 않는다. 자유 연습은 단계 개방에 반영하지 않는다.

전략 힌트는 확정 위치·순서·인접을 확인하는 방법이다. 두 번째 힌트는 첫 조건을 강조하고 해석 방법을 설명한다. 풀이 직접 열람은 별도 안내를 펼쳐 종료 버튼을 누르면 0점으로 끝낸다. 결과에서는 유효 배치와 조건을 하나씩 적용해 가능한 배치를 좁히는 한 가지 풀이, 새로 확정된 대상의 자리, 마지막 제출의 조건별 설명을 제공한다.

## 저장·복구·계정

새로고침·탭 숨김·나가기는 같은 문제·작성 중 배치·마지막 제출·도움·확인 횟수를 보존하고 중단 이력을 남긴다. 조건 피드백을 읽다가 중단했다면 그 피드백 화면으로 복구한다. 실제 배치는 보존하고 선택 강조만 해제한다.

기존 IndexedDB 버전과 계정별 저장 공간에 arrangement-v1을 추가한다. 한 퍼즐 결과는 answers 1개, 확인 횟수와 마지막 제출로 저장하며 기존 네 게임의 기록을 보존한다. 완료 결과만 기존 회원 API로 동기화하고 진행 중인 퍼즐은 현재 기기에 남는다. 서버는 검수된 조건·배치·최종 판정·도움·종료 상태를 검증하고 점수와 게임별 진행을 계산한다. 개인 imported/unverified 기록으로, 공식 경쟁에는 사용하지 않는다.

추가 SQL·환경변수는 없다. 기존 계정 업데이트 SQL(0001)이 적용된 Vercel·Supabase 구성을 사용한다. 로컬 HTTP/PGlite 검증은 실제 운영 DB·TLS·풀러 검증을 대체하지 않는다.

## 검증 도구와 남은 작업

단위 검증은 30단계의 서로 다른 120개 문제를 독립적으로 모든 배치와 비교한다. 조건 의미·복수 해답 예시·조건 필요성·교환·수정 후 도움·점수·중단·부정한 저장 자료·기존 저장 호환을 검사한다. 브라우저에서는 실제 배치·기록·독립된 단계·키보드·드래그·모바일 큰 글자·복구·계정 저장과 다른 브라우저 조회를 확인한다.

프로덕션 화면 감사는 `node scripts/audit-arrangement.mjs`로 실행한다. 기본 주소는 localhost:3100이며 ARRANGEMENT_BASE_URL로 바꿀 수 있으나 로컬 호스트만 허용한다. PC에서 실제 게스트 플레이로 30단계를 모두 풀어 개방하고, 그 로컬 기록으로 360·768px 대표 단계와 큰 글자를 확인한다. test-results/arrangement-production에 캡처와 결과를 남긴다. 이번 검증은 PC 30단계 해결·저장과 45개 입력 화면 상태를 통과했다.

공식 경쟁·쉬운 조건의 자동 보충 연습·장기 복습 추천, 실제 시니어 사용자·실기기 난도와 교육 효과 검증은 후속 작업이다.
