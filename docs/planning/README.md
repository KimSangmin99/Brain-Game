# 개발 준비 문서 안내

작성일: 2026-11-05 · 상태: 구현 기준안 v0.2

사용자 확정 사항은 8종 게임, 개인별 독립 진행, 한국어 모바일·PC 웹, 미래 연구소, ID·비밀번호와 선택 복구 이메일, 무료 제공, 비동기 경쟁이다. 현재 작업은 문서 작성이다.

새로 정의한 수치와 기술 선택은 제작자가 제안한 **구현 기본값**이다. 사용자 테스트를 통과한 수치나 사용자가 개별 승인한 사항이라는 뜻이 아니다. 구현 시 기본값을 사용하고, 변경 시 규칙 버전을 올려 기록 비교 범위를 보존한다.

## 읽는 순서

1. [제품 방향](product-plan.md): 대상·가치·범위.
2. [학습 설계](game-learning-design.md): 교육 목표·전략·해설.
3. [게임 상세 명세](game-specifications.md): 수치·채점·상태·대표 문제.
4. [화면 명세](screen-flows.md): 화면 구성·조작·예외 흐름.
5. [계정·기록·경쟁 정책](service-policies.md): 저장·복구·병합·경쟁 운영.
6. [기술·데이터·API 설계](technical-design.md): 구현 구조와 계약.
7. [개발 순서와 검증 기준](implementation-plan.md): 작업 단위·완료 조건·출시 전 작업.

같은 주제에 충돌이 있으면 사용자 지시를 최우선으로 하고, 상세 수치는 게임 상세 명세, 서비스 동작은 서비스 정책, 인터페이스는 기술 설계를 따른다. 기존 v0.1 문서의 ‘추후 결정’ 중 이 문서 모음에 기본값이 있는 항목은 이제 구현 기준안이 있는 상태다.

## 준비 상태

핵심 기능 구현을 시작할 수 있는 문서 기준안을 마련했다. 실제 구현·보안 검증·플레이테스트·240개 스테이지의 콘텐츠 검수는 아직 완료하지 않았다. 개발 착수와 출시 완료는 서로 다른 단계다.

개발 중 확정할 항목: 프레임워크 정확한 패치 버전, 기기별 타이밍 허용 오차, 플레이테스트 이후 난이도 조정.

외부 배포 전 필요한 운영자 선택: 최종 서비스명·도메인, 호스팅과 메일 서비스·비용, 개인정보 처리방침의 운영자·연락처. 이 정보 없이도 로컬 구현과 테스트는 가능하다. 실제 외부 서비스 구매·설정·게시 승인을 이 문서가 대신하지 않는다.
