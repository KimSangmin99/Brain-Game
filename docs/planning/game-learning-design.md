# 게임·학습 설계서

문서 상태: 검토용 초안 v0.1 · 작성일: 2026-11-05 (한국 시간)

상위 문서: [제품 기획서](product-plan.md)

수치·채점·통과·상태 처리의 구현 기본값은 [게임 상세 명세](game-specifications.md)에 정의한다. 이 문서는 학습 목적과 설명 방식의 근거로 유지한다.

게임 규칙과 학습 흐름을 설계한 문서다. 아래 단계 수·문항 수·통과 수치는 플레이테스트 전의 제안이며 검증 완료를 의미하지 않는다. 여기서의 학습 목표는 게임 내에서 익힐 전략과 관찰 가능한 수행 목표다. 일상 능력의 향상이나 전략 사용 자체를 점수만으로 입증하지 않는다.

## 1. 공통 학습 설계

### 1.1 콘텐츠 단위

- **문항:** 한 번 답을 확정하는 문제 또는 퍼즐.
- **스테이지:** 한 가지 학습 목표를 확인하는 문항 묶음. 복잡한 논리 퍼즐은 한 문제로 구성할 수 있다.
- **구간:** 입문·응용·심화. 각 10개 스테이지를 초기 기준으로 한다.
- **보충 연습:** 어려웠던 조건을 단순화한 새 문제. 원래 스테이지의 난이도를 몰래 바꾸지 않는다.
- **복습:** 이전 목표를 동급의 새 문제로 다시 확인하는 선택형 활동.

구간 경계에서는 지금까지 익힌 규칙을 조합한 문제를 제공한다. 단순히 숫자만 키운 문제를 30개 배치하지 않는다. 구체적인 내용은 학습 목표별 콘텐츠 목록으로 작성한다.

### 1.2 결과와 해설

모든 게임의 결과는 다음 질문에 답한다.

1. 내가 무엇을 제출했는가?
2. 어느 조건을 만족하거나 놓쳤는가?
3. 정답은 왜 성립하는가?
4. 다음 문제에 적용할 수 있는 전략은 무엇인가?

설명은 사실과 제안을 구분한다. 예를 들어 ‘행동을 보면 집중력이 부족합니다’라고 단정하지 않고 ‘두 조건 중 모양 조건을 다시 확인해 보세요’라고 안내한다. 새로운 문제에서의 수행을 확인하기 전에는 전략을 익혔다고 확정하지 않는다.

### 1.3 시간과 실패

- 학습에서는 정확한 해결과 규칙 이해를 우선한다.
- 기억 자극의 표시, 주의 과제의 응답 구간처럼 규칙의 일부인 시간은 단계별로 정한다.
- 일반 퍼즐의 생각 시간을 일괄 제한하지 않는다.
- 실패 후에는 바로 재도전·해설·보충 연습 중 선택할 수 있다. 완료한 진행도는 보존한다.
- 일시정지·배속·도움 등 출제 조건이 달라지면 동일 조건의 최고 기록과 섞지 않는다.

## 2. 패턴 복원 · 기억

**학습 목표:** 위치의 관계를 살펴보고, 같은 조건의 새로운 패턴을 정확히 재현한다.

- **규칙:** 격자의 일부 칸을 일정 시간 보여준 뒤 가린다. 사용자는 기억한 칸을 선택하고 확정한다. 확정 전 선택을 수정할 수 있다.
- **정답:** 선택 집합이 제시 집합과 정확히 일치한다. 부분 일치는 피드백에 사용하고 정답으로 세지 않는다.
- **실패:** 스테이지의 정답 목표 미달. 오선택 한 번으로 전체 진행을 잃지 않는다.
- **가르칠 전략:** 칸을 하나씩 외우기, 인접한 칸을 묶기, 모양이나 기준 위치와의 관계로 기억하기.
- **입문 → 응용 → 심화:** 작은 격자·적은 위치 → 위치 수와 격자 확대 → 비슷한 위치 패턴 구분. 한 단계에서 여러 난도 변수를 급격히 바꾸지 않는다.
- **해설:** 원래 위치·선택 위치를 표식으로 비교한다. 정답 칸, 놓친 칸, 잘못 선택한 칸을 색상 외 표식으로도 구분한다.
- **보충 연습:** 격자와 표시 시간은 유지하고 기억할 칸 수를 줄인다. 전략을 익힌 뒤 원래 조건의 새 패턴으로 돌아간다.
- **측정:** 같은 격자·칸 수·표시 시간에서의 완전 정답률. 도움·표시 시간 변경 여부를 분리한다.
- **공식 경쟁:** 동일 난도의 고정 문항 묶음에 대한 완전 정답 수 우선. 빠른 클릭을 주요 점수로 삼지 않는다.
- **검수:** 제시 패턴과 판정의 일치, 터치 오입력 방지, 반복 노출 이력, 보기 크기 변화에 따른 난도 차이.

## 3. 시퀀스 기억 · 기억

**학습 목표:** 항목의 정체와 등장 순서를 구분하고, 새로운 순서를 재현한다.

- **규칙:** 도형·위치 등의 항목이 차례대로 나타난다. 사용자는 순서대로 입력한 뒤 답을 확정한다. 입력 중 정오를 알려 정답 순서를 유추하게 하지 않는다.
- **정답:** 순서와 길이가 모두 일치한다.
- **실패:** 해당 스테이지의 성공 목표 미달. 결과에서 틀린 순서와 놓친 항목을 확인할 수 있다.
- **가르칠 전략:** 짧은 묶음으로 나누기, 순서대로 되짚기, 비슷한 항목의 차이 확인하기.
- **입문 → 응용 → 심화:** 짧고 구별이 쉬운 순서 → 길이 증가 → 반복 항목과 비슷한 항목이 포함된 순서. 반복 허용은 새 규칙으로 안내한다.
- **해설:** 제시 순서와 입력 순서를 나란히 보여준다. ‘항목 자체의 오답’과 ‘순서의 오답’을 구분한다.
- **보충 연습:** 짧은 길이와 여유 있는 표시 간격에서 새 순서를 제공한다.
- **측정:** 같은 길이·항목 종류·표시 간격에서의 완전 재현률. 가장 긴 한 번의 성공과 안정적인 반복 성적을 구분한다.
- **공식 경쟁:** 정해진 난도별 순서의 완전 재현 수 우선. 입력 속도는 주 점수에서 제외한다.
- **검수:** 중복 항목 판정, 입력 수정, 누락·초과 입력, 기기별 표시 순서·간격.

## 4. 규칙 분석 · 추론

**학습 목표:** 여러 사례에서 변화하는 속성을 찾고, 가능한 규칙을 반례로 좁힌다.

- **규칙:** 도형의 배열·변화를 보고 선택지에서 다음 항목 또는 빈칸을 고른다. 문제 유형마다 허용하는 규칙의 범위를 안내한다.
- **정답:** 안내한 규칙 범위 안에서 제시 사례 전체를 만족하고, 정답 선택지가 하나로 결정된다.
- **실패:** 정답 목표 미달. 문제마다 확정 후 결과를 제공한다.
- **가르칠 전략:** 색·개수·방향을 따로 관찰하기, 한 사례에만 맞는 규칙을 배제하기, 나머지 사례로 가설을 확인하기.
- **입문 → 응용 → 심화:** 한 속성의 변화 → 두 속성의 변화 → 교대·결합 규칙. 새 규칙은 예제로 먼저 소개한다.
- **해설:** ‘정답은 3번’에서 끝내지 않고 각 사례에 규칙이 어떻게 적용되는지 표시한다. 오답 선택지가 놓친 조건도 설명한다.
- **보충 연습:** 관계없는 속성을 제거한 문제부터 시작해 원래 복잡도의 새 문제로 이어간다.
- **측정:** 규칙 종류·복잡도별 정답률과 도움 사용. 시간은 동일 조건에서의 참고 기록이다.
- **공식 경쟁:** 정답 수 우선, 시간은 보조 기준 사용 여부를 검증한다.
- **검수:** 허용 규칙군의 다른 규칙으로 복수 선택지가 성립하면 수정한다. 출제자의 의도만으로 다른 타당한 답을 오답 처리하지 않는다.

## 5. 코드 브레이커 · 추론

**학습 목표:** 피드백을 조건으로 해석하고, 앞선 결과와 모순되지 않는 가설을 세운다.

- **규칙:** 숨겨진 기호 조합에 대해 추측을 제출한다. ‘기호와 위치 모두 일치’와 ‘기호는 맞고 위치는 다름’의 개수를 알려준다. 모든 추측과 피드백을 계속 볼 수 있다.
- **정답:** 정해진 시도 안에 전체 조합을 해독한다.
- **실패:** 시도 소진. 해설 뒤 새 조합으로 재도전한다. 학습에서는 중도에 풀이를 열 수 있다.
- **가르칠 전략:** 위치 조건과 포함 조건을 구분하기, 이미 배제된 가능성 제거하기, 새 추측이 이전 피드백과 맞는지 확인하기.
- **입문 → 응용 → 심화:** 짧은 조합·기호 중복 없음 → 길이와 기호 수 증가 → 중복 허용. 시도 수는 문제 난도에 맞춰 검증한다.
- **해설:** 각 피드백으로 알 수 있는 사실과 아직 결정할 수 없는 사실을 구분한다. 유일하지 않은 중간 상태에서 특정 다음 수를 유일한 답처럼 설명하지 않는다.
- **보충 연습:** 기호 수·조합 길이를 줄이고, 피드백 해석 예제를 제공한다.
- **측정:** 같은 규칙·난도에서의 해독 성공률과 시도 수. 피드백과 모순된 추측을 했는지 여부는 학습 참고로만 사용한다.
- **공식 경쟁:** 해독 성공 수 → 사용한 시도 수. 시간의 동점 기준 사용은 검증 후 정한다.
- **검수:** 중복 기호의 피드백은 먼저 정확한 위치 일치를 센 후 남은 기호를 한 번씩만 대응한다. 모든 추측 이력이 보이고 허용 시도 내 해결 가능한지 점검한다.

## 6. 조건 배열 · 논리

**학습 목표:** 명시된 조건을 관계로 해석하고, 여러 조건을 함께 만족하는 배치를 만든다.

- **규칙:** 사람·물건의 위치에 관한 단서를 보고 배치한다. 자유롭게 수정한 뒤 답을 확정한다. 드래그와 선택 후 배치를 함께 제공한다.
- **정답:** 모든 조건을 만족한다. 복수 해답 허용 문제는 가능한 모든 해답을 인정한다.
- **실패:** 확정한 답이 일부 조건을 위반하면 결과에서 확인 후 수정하거나 새 문제를 선택한다.
- **가르칠 전략:** 확정 조건부터 배치하기, 가능한 위치 표시하기, 새 배치가 다른 조건과 충돌하는지 확인하기.
- **입문 → 응용 → 심화:** 직접 위치 → 앞뒤·인접 관계 → 여러 조건을 연결한 간접 추론.
- **해설:** 위반한 조건과 해당 위치를 연결한다. 한 가지 타당한 풀이 순서를 보여주되 다른 유효한 접근을 배제하지 않는다.
- **보충 연습:** 대상 수와 간접 관계를 줄이고 같은 조건 표현을 다시 익힌다.
- **측정:** 난도별 독립 해결 여부, 확정 시 조건 위반 수, 도움 사용. 편집 중의 탐색을 오답으로 세지 않는다.
- **공식 경쟁:** 해결한 문제 수 우선. 수정·되돌리기 횟수 자체를 불이익으로 삼지 않는다.
- **검수:** 해 존재 여부, 유일성 의도, 복수 해답 인정, 단서 표현의 모호함, 배치 대체 조작.

## 7. 경로 설계 · 논리

**학습 목표:** 목표와 제약을 먼저 파악하고, 전체 경로를 계획하며 수정한다.

- **규칙:** 시작점에서 목표점까지 경로를 만든다. 장애물을 피하고 필수 지점·이동 횟수 등 공지한 조건을 충족한다. 확정 전 자유롭게 되돌릴 수 있다.
- **정답:** 모든 필수 조건을 만족하는 유효 경로. 최단 경로가 필수인 문제는 이를 명시한다.
- **실패:** 경로를 확정했을 때 위반한 조건이 있으면 수정할 수 있다.
- **가르칠 전략:** 필수 지점 먼저 확인하기, 막다른 길 예상하기, 목표에서 거꾸로 생각하기, 경로를 구간으로 나누기.
- **입문 → 응용 → 심화:** 단순한 장애물 → 여러 필수 지점 → 방문 순서와 이동 제약 조합.
- **해설:** 끊긴 부분·통과하지 않은 지점·초과한 이동 조건을 표시한다. 유효 경로가 여럿이면 예시 경로임을 명시한다.
- **보충 연습:** 필수 지점이나 제약을 줄인 유사 지도를 제공한다.
- **측정:** 조건별 해결 여부, 필수 조건 충족, 명시된 효율 목표 달성. 탐색 과정의 되돌리기를 실패로 취급하지 않는다.
- **공식 경쟁:** 해결 수 우선. 경로 길이는 해당 문제에서 최적화 목표로 공지한 경우에만 반영한다.
- **검수:** 도달 가능성, 제약 동시 충족, 유효 경로 인정, 경로 입력과 키보드·선택 조작.

## 8. 신호 탐색 · 주의·판단

**학습 목표:** 목표 조건을 유지하며 대상과 방해 요소를 구분한다.

- **규칙:** 화면에서 제시 조건에 맞는 대상을 선택한다. 규칙에 따라 선택 즉시 판정하거나 최종 확정한다. 두 방식을 한 기록 묶음에서 혼용하지 않는다.
- **정답:** 대상 식별이 정확하다. 제한 시간형과 충분한 탐색 시간형은 별도 조건으로 기록한다.
- **실패:** 목표 정확도 또는 정해진 오선택 허용 기준 미달. 기준은 시작 전에 표시한다.
- **가르칠 전략:** 목표 조건 다시 확인하기, 일정한 순서로 살펴보기, 한 가지 눈에 띄는 속성에만 반응하지 않기.
- **입문 → 응용 → 심화:** 한 속성 → 두 속성 결합 → 비슷한 방해 대상과 탐색 범위 증가.
- **해설:** 놓친 대상과 오선택을 나눠 보여주고 각각의 조건 충족 여부를 설명한다.
- **보충 연습:** 방해 요소를 줄이고, 시간 압박을 완화한 조건으로 연습한다.
- **측정:** 정확도, 놓친 수, 오선택 수, 동일 조건의 정확한 처리량. 오선택을 감수한 빠른 입력이 이득이 되지 않도록 채점한다.
- **공식 경쟁:** 정확도 기준과 정확한 처리량을 함께 사용한다. 입력 방식에 따른 순위를 구분한다.
- **검수:** 화면 크기에 따른 대상 크기·밀도·스크롤 차이, 색각 차이, 작은 터치 영역, 무작위 연타의 점수 이득.

## 9. 룰 스위치 · 주의·판단

**학습 목표:** 현재 적용할 규칙을 확인하고, 규칙이 바뀔 때 응답 기준을 전환한다.

- **규칙:** 현재 지시에 따라 도형의 색·모양·방향 중 필요한 속성으로 응답한다. 현재 규칙과 입력 설명을 계속 표시한다.
- **정답:** 해당 문항에서 공지된 규칙에 맞는 응답이다.
- **실패:** 문항 묶음의 목표 정확도 미달. 시간 초과는 오답과 구분해 기록한다.
- **가르칠 전략:** 자극에 반응하기 전에 현재 지시 확인하기, 지시가 바뀐 순간 기준을 다시 세우기.
- **입문 → 응용 → 심화:** 단일 규칙 → 충분한 예고가 있는 전환 → 전환 빈도와 방해 속성 증가. 규칙 수와 응답 시간을 동시에 급격히 바꾸지 않는다.
- **해설:** 당시 지시·실제 자극·선택 답·올바른 판단 기준을 함께 표시한다.
- **보충 연습:** 단일 규칙을 다시 연습한 뒤 여유 있는 전환 조건으로 이어간다.
- **측정:** 규칙별 정확도, 전환 직후 정확도, 무응답 수, 같은 조건에서 정답 반응 시간. 이를 개인의 인지 상태 진단으로 표현하지 않는다.
- **공식 경쟁:** 정확도와 정확한 처리량을 사용한다. 입력 방식과 표시 조건을 동일하게 맞춘다.
- **검수:** 지시 전환 시점, 응답 판정 경계, 설정에 따른 지시 가독성, 색상 외 구분, 기기 지연.

## 10. 스테이지 상세 예시 A: 패턴 복원

다음은 제작 형식을 보여주는 예시이며 수치는 미검증이다.

| 항목 | 설계안 |
| --- | --- |
| 학습 목표 | 인접한 위치를 묶어 관찰하는 전략을 접하고 새 패턴을 재현 |
| 선수 규칙 | 칸 선택·해제·확정 조작을 이해함 |
| 조건 | 3×3 격자, 목표 3칸, 표시 3초, 5문항 |
| 안내 | ‘칸들의 위치 관계를 살펴보세요. 붙어 있는 칸을 묶어 기억해도 좋아요.’ |
| 도전 | 문항별 새 패턴을 제시한 뒤 선택·확정. 응답 속도에 점수 보너스 없음 |
| 통과안 | 5문항 중 4문항에서 전체 패턴 일치. 도움이 있었는지는 별도 표시 |
| 전략 힌트 | 같은 행·인접 위치 등 관찰 방법을 예시 패턴으로 설명 |
| 문제 힌트 | 원 패턴을 다시 보여주는 경우 도움 사용으로 표시 |
| 결과 | 완전 정답 수, 놓친 칸·추가 선택 칸, 도움 여부 |
| 해설 문구 | ‘이 패턴에서는 왼쪽의 두 칸이 붙어 있었어요. 다음에는 묶음과 떨어진 칸을 나누어 살펴보세요.’ |
| 보충 연습 | 같은 격자·표시 시간에서 목표 2칸의 새 패턴 |
| 복습 | 같은 조건의 다른 패턴으로 재확인. 이미 본 정답을 반복해서 통과한 기록과 구분 |

이 결과만으로 묶음 전략을 실제로 사용했다거나 기억력이 향상됐다고 단정하지 않는다. 관찰 가능한 사실은 해당 조건의 문제에 대한 수행이다.

## 11. 스테이지 상세 예시 B: 조건 배열

문제 예시: 왼쪽부터 1·2·3번인 세 자리에 A·B·C를 한 명씩 배치한다. ‘C는 3번 자리입니다’, ‘A는 B의 바로 왼쪽입니다’라는 조건을 제공한다.

- **학습 목표:** 확정된 위치를 먼저 반영하고 인접 조건을 적용한다.
- **정답:** 1번 A, 2번 B, 3번 C. 두 조건을 동시에 만족한다.
- **조작:** 대상을 선택한 뒤 자리를 선택한다. 확정 전 위치 변경 가능.
- **전략 힌트:** ‘위치가 바로 정해지는 조건을 먼저 찾아보세요.’
- **문제 힌트:** ‘C의 조건부터 적용해 보세요.’
- **해설:** ‘C가 3번이므로 A와 B는 1·2번에 놓입니다. A가 B의 바로 왼쪽이므로 A는 1번, B는 2번입니다.’
- **피드백 예시:** 제출이 B·A·C라면 ‘C의 위치는 맞습니다. A가 B의 바로 왼쪽인지 확인해 보세요.’라고 안내한다.
- **독립 해결 확인:** 이름과 단서 배치를 바꾼 동급 문제를 도움 없이 해결하는지 관찰한다.

본 예시는 규칙 설명을 위한 기획 콘텐츠다. 앱에서 실제 출제·판정된 결과가 아니다.

## 12. 학습 콘텐츠 검토표

각 스테이지를 작성할 때 아래 내용을 함께 검토한다.

- 목표를 한 문장으로 설명할 수 있는가?
- 규칙을 익힌 사람이 설명 없이도 조작할 수 있는가?
- 선행 지식이나 새로운 규칙을 미리 소개했는가?
- 제시 정보와 정답 판정이 일치하는가?
- 문제 풀이의 타당성과 필요한 경우 정답 유일성을 확인했는가?
- 오답 피드백이 관찰 사실에 근거하는가?
- 힌트가 전략 → 조건 → 풀이 순서로 도움 수준을 구분하는가?
- 풀이를 본 뒤 다른 문제로 독립 해결을 확인할 수 있는가?
- 배경색·작은 글자·소리·정밀한 손동작이 의도하지 않은 장벽이 되지 않는가?
- 쉬운 보충 문제와 원래 목표로 돌아오는 경로가 있는가?
- 동일 조건 기록끼리 비교하고, 도움·반복 노출·속도 변경을 구분하는가?
- 기억·추론·논리·주의의 실제 생활 전이를 입증하지 않은 상태에서 과장된 효과를 표현하지 않는가?

## 13. 아직 검증하지 않은 것

게임은 구현하지 않았고, 240개 스테이지의 실제 문제 묶음도 제작·검수하지 않았다. 플레이 시간·정답률·단계별 난도·표시 시간·통과 기준·복습 주기·학습 성과는 사용자 검증 전이다. 이 문서는 상세 콘텐츠 제작과 화면 설계의 기준안이며, 검증 결과에 따라 수정한다.
