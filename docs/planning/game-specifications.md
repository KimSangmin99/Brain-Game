# 8종 게임 구현 명세

상태: v0.2 구현 기본값. 수치는 플레이테스트 전이며 [학습 설계](game-learning-design.md)와 함께 사용한다.

## 1. 공통 계약

- 게임 ID: pattern, sequence, rule, code, arrangement, route, search, switch.
- 모드: stage / practice / official. 같은 규칙 버전·난도·도움·시간 조건끼리만 성적 비교.
- 스테이지는 게임별 1~30. 1부터 열리고 통과 시 다음 하나 개방. 완료한 단계 재선택 가능. 게임 간 잠금 없음.
- 단계 묶음 B1=1~5, B2=6~10, B3=11~15, B4=16~20, B5=21~25, B6=26~30.
- 각 묶음의 첫 단계는 안내된 연습 1문항 후 본문항, 나머지 단계는 본문항만. 연습은 점수 제외. 묶음별 핵심 규칙은 아래 표로 고정하고 문제 내용만 교체한다.
- 상태: 준비 → 안내 → 제시 → 응답 → 확정 → 피드백 → 다음 문항 → 결과. 규칙상 제시가 필요 없는 퍼즐은 제시 후 즉시 응답 상태.
- 답안은 확정 전 수정 가능. 확정 요청 중 중복 버튼 비활성화. 확정 후 원 답안 변경 불가.
- ‘건너뛰기’는 해당 문항 0점. 공식에서는 확인 후 확정하며 돌아올 수 없음.
- 일반 모드의 힌트 1·2는 assisted=true, 풀이 열람은 revealed=true. 풀이를 본 문항은 해결 수에 포함하지 않는다. 다른 새 문항으로 재도전한다.
- 일반 규칙 보기만으로 assisted를 켜지 않는다. 일반 모드의 틀린 최종 제출 후 구체적인 조건 피드백을 보고 수정한 해결은 assisted=true로 기록한다.
- 스테이지 통과는 도움 여부와 별개로 아래 기준 적용. 학습 성취 ‘독립 해결’은 통과하면서 assisted/revealed/노출 후 중단이 모두 false일 때 부여.
- 학습 상태: 아직 응시 없음=처음 접함, 응시했지만 독립 통과 없음=연습 중, 해당 목표를 서로 다른 문제 묶음에서 2회 독립 통과=목표 달성. 완료 표시를 소급 취소하지 않는다.
- 복습 추천: 최근 완료한 목표 중 마지막 독립 해결 후 3일이 지났거나 최근 2회 미통과한 목표를 최대 3개 제안. 초기 경험 설계값이며 최적 학습 간격이라고 주장하지 않는다.
- 일반 모드는 응답 시간 무제한. 제시 중 창 숨김·새로고침은 해당 문항을 중단 처리하고 새 문항으로 교체; 기존 완료 문항은 보존하고 독립 성취는 해당 세션에서 제한한다. 논리 퍼즐은 응답 초안을 저장해 계속할 수 있다.
- 공식 모드는 힌트·풀이·즉시 정오 해설 없음. 코드의 규칙상 피드백만 예외. 자세한 중단 정책은 [서비스 정책](service-policies.md) 참조.

## 2. 난이도와 통과 기준

표의 ‘/’는 B1부터 B6까지 순서다. 모든 문제는 stageId, contentVersion, rulesVersion, 난도 값, 정답 판정 자료, 해설, 노출 이력을 갖춘다.

| 게임 | B1 / B2 / B3 / B4 / B5 / B6 조건 | 스테이지 본문항·통과 |
| --- | --- | --- |
| 패턴 복원 | 격자 3/3/4/4/5/5; 목표 칸 2/3/4/5/6/7; 표시 초 3/3/4/4/5/5 | 새 패턴 5문항 중 완전 일치 4개 |
| 시퀀스 기억 | 항목 후보 4/4/6/6/6/6; 길이 3/4/4/5/6/7; 반복 허용 아니오/아니오/아니오/아니오/예/예; 항목당 900ms + 빈 간격 300ms | 새 순서 5문항 중 완전 일치 4개 |
| 규칙 분석 | 단일 속성 순환/단일 속성 증감/두 속성 독립/교대 부분열/독립+교대/앞서 배운 규칙 혼합 | 4지선다 5문항 중 4개 |
| 코드 브레이커 | 길이 3/3/4/4/4/5; 기호 종류 4/5/5/6/6/6; 중복 아니오/아니오/아니오/아니오/예/예; 시도 6/6/7/8/9/10 | 조합 1개 해독 |
| 조건 배열 | 대상 3/3/4/4/5/6; 직접 위치/직접+바로 인접/순서/순서+인접/부정 조건 포함/전체 혼합 | 퍼즐 1개, 모든 조건 만족 |
| 경로 설계 | 격자 4/4/5/5/6/6; 필수 지점 0/1/1/2/2/3; B5부터 방문 순서, B6은 이동 상한 포함 | 퍼즐 1개, 모든 조건 만족 |
| 신호 탐색 | 격자 3/3/4/4/5/5; 목표 수 2/3/3/4/5/6; B1~2 한 속성, B3~6 두 속성; B4부터 유사 방해 대상 | 3개 보드의 평균 점수 ≥8000 |
| 룰 스위치 | 규칙 수 1/1/2/2/2/3; 전환 간격 문항 수 없음/없음/5/4/3/2; 응답 초 5/4/5/4/4/4 | 20문항 중 16개 정답 |

규칙 분석의 색 순환은 모양·표식으로도 구분한다. 배열 단서 수는 대상 수 이상으로 시작하되 필요한 조건을 충족하는 해가 유일해질 때까지 검수한다. 경로 장애물은 경로의 존재를 확인한 검수 자료에 포함한다. 표 자체로 모든 문제가 풀린다고 간주하지 않는다.

각 게임의 30개 단계는 고유 목표·콘텐츠 목록을 가진다. B1~B6의 각 5개 단계의 교육 역할은 순서대로 ‘새 규칙 도입 / 기본 적용 / 흔한 혼동 구분 / 변형 적용 / 구간 종합’이다. 묶음 내 수치가 같아도 내용과 해설 목표를 다르게 제작한다.

## 3. 입력과 정답 판정

| 게임 | 입력·판정 | 경계 조건 |
| --- | --- | --- |
| pattern | 칸 선택 집합과 제시 집합의 완전 동일 | 선택 수가 목표 수가 되어야 확정 가능; 빈·초과·중복 좌표 거부 |
| sequence | 항목 ID 배열의 길이·순서 완전 동일 | 입력 끝 지우기 허용; 길이 충족 시 확정; 입력 중 정오 노출 금지 |
| rule | 선택지 ID가 검수된 정답 ID인지 확인 | 문제에 명시한 규칙군에서 다른 유효 답이 생기면 출제 제외 |
| code | 길이·후보·중복 정책 확인 후 exact와 misplaced 계산 | 잘못된 형식은 시도 차감 없음. exact 우선 대응 후 남은 기호를 1회씩만 대응 |
| arrangement | 각 대상이 서로 다른 슬롯에 1회 배치되고 모든 술어 충족 | 편집 중 자리 교체 가능. 여러 해 허용 문제는 모든 유효 해 인정 |
| route | 상하좌우 인접 경로, 장애물 회피, 지정 시작·끝, 필수 방문·순서·상한 검사 | 대각선·칸 재방문 금지. 이동 수=경로 칸 수−1. 확정 전 되돌리기 무제한 |
| search | 확정한 선택 집합의 TP·FP·FN 집계 | 선택 시 정오 노출 없음, 확정 전 취소 가능. 목표 T>0 보장 |
| switch | 당시 표시한 규칙에 따른 응답 1회 | 첫 유효 입력으로 확정, 무응답은 오답과 별도 집계. 자극 전 입력 무시 |

룰 스위치는 이진 응답으로 시작한다. 색 규칙=밝은 표식/어두운 표식, 모양 규칙=원/삼각형, 방향 규칙=위/아래. 응답 버튼에 현재 의미와 키를 항상 표기한다. 문항 종료 후 빈 간격 500ms, 규칙 변경 시 안내 1000ms를 추가하고 응답 시간에서 제외한다. 입문 단계의 다른 속성은 중립으로 표시한다.

## 4. 점수와 공식 조건

점수 범위는 게임 내 0~10000이다. 총합 IQ·게임 간 통합 순위 없음. 소수점은 최종 단계에서 버린다. 학습용 점수에도 동일 공식을 적용하되 도움·중단·시간 설정을 함께 표시한다.

| 게임 | 점수 공식 | 공식 1회 묶음 |
| --- | --- | --- |
| pattern, sequence, rule | floor(10000 × 완전 정답 문항 / 전체 문항) | B3 조건의 5문항 |
| code | 실패=0; 성공=8000+floor(2000×(M−G)/(M−1)); M=최대 시도, G=사용 시도 | B3 조합 3개, 문항 점수 평균 |
| arrangement | 첫 확정에서 조건 충족=10000, 그 외=0 | B3 퍼즐 3개 평균. 일반 모드는 수정 후 해결해도 10000이나 도움 상태 표시 |
| route | 실패=0; 성공=8000+floor(2000×L/S); L=최단 유효 이동 수, S=제출 이동 수 | B3 퍼즐 3개 평균. 효율이 공식 목표임을 시작 전에 공지 |
| search | 보드별 floor(10000×max(0,TP−FP)/T); T=실제 목표 수. 평균으로 세션 점수 | B3 보드 3개, 보드당 30초. 시간 종료 시 현재 선택 자동 확정 |
| switch | floor(10000×정답 수/20) | B3 조건 20문항 |

시간 동점 기준은 첫 버전에 사용하지 않는다. 같은 점수는 공동 순위(1,1,3). 시간은 설명된 제한과 개인 참고 기록에만 사용한다. 경로 L은 검수 시 구하며 시작=목표인 문제는 제외해 L>0을 보장한다.

신호 탐색의 일반 스테이지는 제한 시간 없이 같은 점수식을 쓴다. 공식과 개인 최고 기록을 섞지 않는다. 룰 스위치의 시간 변경 연습도 별도 조건으로 집계한다. 입력 방식별 공식 구분은 search·switch에만 적용한다.

## 5. 대표 문제와 판정 예시

이 예시는 구현 검증 자료이며 실제 240개 콘텐츠의 제작 완료를 뜻하지 않는다. 좌표는 (행,열), 왼쪽 위=(1,1).

| 게임 | 문제·제출 | 정답·예상 결과·해설 |
| --- | --- | --- |
| pattern | 3×3 목표 {(1,1),(1,2)}; 같은 집합 제출 | 정답. 왼쪽 위에서 가로로 인접한 두 칸. {(1,1),(2,1)}은 오답 |
| sequence | 원→삼각형→사각형 | 동일 순서만 정답. 원→사각형→삼각형은 항목이 같아도 순서 오답 |
| rule | ‘항상 90도 시계 방향 회전’ 유형: ↑,→,↓ 다음 항목; 선택 ↑/→/↓/← | ←. 각 화살표가 한 번씩 오른쪽으로 회전함 |
| code | 정답 A B A C, 추측 A A B D, 중복 허용 | exact=1, misplaced=2. 첫 A 위치 일치, 남은 A·B는 위치가 다름 |
| arrangement | C=3번, A는 B 바로 왼쪽; 대상 A/B/C | A B C. C 고정 후 남은 두 자리의 인접 조건 적용 |
| route | 3×3, 시작(1,1), 끝(3,3), 장애물(2,2), 필수(1,3) | (1,1)→(1,2)→(1,3)→(2,3)→(3,3), L=S=4, 10000점 |
| search | 실제 목표 3개, 올바른 선택 2개+오선택 1개 | TP=2, FP=1, FN=1, 점수3333. 무차별 선택은 오선택 차감 |
| switch | 현재 규칙 ‘모양’, 밝은 원에 아래 화살표 표시, 버튼 원/삼각형 | 원이 정답. 밝기·화살표는 현재 판단 기준에 포함되지 않음 |

필수 반례: code의 중복 과계산, arrangement의 유효 복수 해답, route의 길이는 짧지만 필수 지점 누락, search의 목표 전부+방해 전부 선택, switch의 응답 시간 경계 전후 입력.

## 6. 콘텐츠 제공 규칙

- 각 스테이지 콘텐츠 묶음에 목표, 파라미터, 문제 또는 검증된 생성 규칙, 정답·검증 자료, 힌트 2단계, 풀이, 대체 문제를 저장한다.
- 입문 예제와 공식 문제 집합은 별도다. 공식 해답·미공개 문항을 브라우저 번들에 포함하지 않는다. 기억 자극은 규칙상 브라우저에 전달되므로 복사 방지를 보장하지 않는다.
- 단계별 검수 완료 대체 문제를 최소 3묶음 준비한다. 반복되면 ‘다시 푸는 문제’로 표시하며 새 문제 독립 성취 횟수에서 제외한다.
- 생성 실패·해 불명확·자료 누락이면 임의 문제를 출제하지 않고 검수된 대체 묶음 사용. 대체도 없으면 해당 단계 일시 이용 불가 안내, 진행도 보존.
- 공개 후 콘텐츠는 불변 버전으로 관리. 정답 오류 발견 시 문제 비공개, 영향을 받은 공식 대회 취소 또는 재개최 정책 적용.
