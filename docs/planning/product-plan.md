# Brain Game 제품 기획서

문서 상태: 제품 방향 기준안 v0.2 · 작성일: 2026-11-05 · 갱신: 2026-11-09 (한국 시간)

후속 상세 설계: [개발 준비 문서 안내](README.md)의 v0.2 구현 기준안을 함께 읽는다. 이 문서의 미정 항목에 상세 명세의 기본값이 있으면 해당 기본값을 적용한다. 사용자 확정 방향은 유지한다.

이 문서는 대화에서 확정한 제품 방향과 이를 구체화한 설계 제안을 구분한다. 전체 제품 방향을 설명하며 실제 구현·배포 현황은 [개발 진행 기록](../development-status.md)을 따른다. 아래의 수량, 판정 방식, 경쟁 운영 규칙은 명시적으로 확정되지 않은 한 검증할 설계안이다.

## 1. 확정한 제품 방향

| 항목 | 결정 |
| --- | --- |
| 제품 성격 | 게임의 재미와 학습 도구의 역할을 함께 갖춘 두뇌 활동 서비스 |
| 주요 대상 | 성인 일반 사용자, 중장년·시니어 |
| 이용 환경 | 모바일·PC 웹, 한국어 우선 |
| 표현 | A 디자인 ‘오늘의 한 걸음’: 밝은 아이보리·차분한 녹색의 두뇌 연습 공간. 큰 글자·한 가지 주 행동·명확한 조작을 우선 (2026-11-09 사용자 선택) |
| 출시 게임 | 기억·추론·논리·주의 분야에 각각 2종, 총 8종 |
| 성장 | 게임별 독립된 스테이지와 레벨 |
| 경쟁 | 비동기 기록 경쟁 |
| 계정 | 가입 없이 체험. ID·비밀번호 가입. 복구 이메일은 선택 연결 |
| 수익 | 현재 추가 구매 없음. 첫 출시 게임은 무료 제공 |
| 제작 | 개인 + AI. 날짜 상한 없이 완료 기준으로 진행 |
| 현재 단계 | 기억 2종·추론 2종·논리 1종과 기본 계정 구현, A 디자인 적용. 나머지 3종과 후속 기능 개발 중 |

첫 콘텐츠 분량의 기준안은 게임별 30개 스테이지, 총 240개다. 사용자 테스트 결과에 따라 분량과 난이도 배치를 재검토한다. 게임 수를 줄이는 변경은 별도 합의가 필요하다.

## 2. 사용자가 얻는 가치

사용자는 원하는 게임에 도전하고, 해결 전략을 배우며, 같은 조건의 새로운 문제에서 자신의 수행 변화를 확인한다. 일상에서의 기억·추론·논리·주의 능력 향상을 제품의 지향점으로 삼되, 제품 기록은 실제로 관찰한 게임 수행을 설명한다.

- 표시 가능한 성과: 정확도, 해결한 문제, 시도 수, 같은 조건의 처리 시간, 도움 사용 여부, 게임별 진행도.
- 게임 점수를 IQ·두뇌 나이·인지 건강 진단으로 환산하지 않는다.
- 반복한 정답을 기억한 결과와 새로운 문제를 해결한 결과를 구분한다.
- 일상 과제의 능력 향상은 게임 점수만으로 입증했다고 표현하지 않는다. 관련 효능 주장은 별도의 근거 검토가 필요하다.

여기서 학습은 우선 기억 전략, 규칙 발견, 조건에 따른 추론, 주의 조절과 같은 해결 전략을 익히는 것을 뜻한다. 교과 지식 퀴즈나 학습 과목 추가는 현재 합의된 범위에 포함하지 않는다.

## 3. 게임과 학습을 연결하는 기본 흐름

`짧은 목표 안내 → 조작 체험 → 도전 → 결과와 해설 → 선택형 보충 연습 → 다음 단계 또는 복습`

1. **목표 안내:** 이번 단계에서 익힐 규칙과 전략을 한 가지씩 설명한다.
2. **조작 체험:** 첫 이용 또는 새 규칙 도입 시 직접 눌러보는 예제를 제공한다. 다시 볼 수 있다.
3. **도전:** 플레이에 필요한 정보만 표시한다. 긴 설명과 효과가 문제를 가리지 않는다.
4. **결과:** 정오, 해당 게임의 주요 기록, 사용한 도움을 표시한다. 정답의 이유를 설명한다.
5. **보충 연습:** 어려웠던 조건을 단순화한 새 문제를 선택할 수 있다. 오답 원인을 단정하지 않는다.
6. **복습:** 이전 목표를 다른 문제로 다시 해결하도록 제안한다. 제안은 강제가 아니다.

학습 설명은 매 판 강제로 반복하지 않는다. 설명을 건너뛰거나 다시 열 수 있고, 해설도 원하는 만큼 살펴볼 수 있다. 공식 응시 중에는 문제 풀이에 영향을 주는 도움을 제공하지 않는다.

### 3.1 진행도와 학습 기록

- 힌트를 사용해 해결해도 스테이지 완료와 다음 단계 개방을 보존한다.
- 힌트 없는 해결, 정확한 해결, 게임별 효율 목표는 별도 성취로 표시한다.
- 학습 기록은 같은 난이도·출제 조건·도움 조건에서 비교한다.
- 오래 접속하지 않았다는 이유만으로 완료 기록이나 레벨을 낮추지 않는다.
- 복습 추천과 스테이지 완료 표시는 독립적이다.
- ‘전략을 실제로 사용했는지’는 정오 기록만으로 확인할 수 없으므로 사용했다고 단정하지 않는다.

학습 상태의 표현안은 ‘처음 접함 / 연습 중 / 목표 달성’이다. ‘복습 추천’은 별도 표시다. 목표 달성의 수치 기준은 게임별로 정하고 플레이테스트에서 조정한다. 단일 점수로 종합 지능을 평가하지 않는다.

### 3.2 도움의 단계

| 단계 | 제공 내용 | 기록 |
| --- | --- | --- |
| 규칙 다시 보기 | 일반 규칙과 조작 설명 | 규칙 열람으로 기록. 정답 단서는 제공하지 않음 |
| 전략 힌트 | 문제에 접근할 방법을 제안 | 힌트 사용 기록 |
| 문제 힌트 | 현재 문제에서 확인할 조건을 강조 | 힌트 사용 기록 |
| 풀이 보기 | 답과 해결 과정을 공개 | 학습 열람으로 기록. 해당 문제의 독립 해결 성취는 부여하지 않음 |

풀이를 본 뒤에는 동급의 다른 문제로 다시 도전할 수 있다. 정답을 열람한 동일 문제는 공식 기록으로 사용하지 않는다.

## 4. 게임 및 모드

게임별 상세 규칙과 학습 목표는 [게임·학습 설계서](game-learning-design.md)에 정의한다.

| 분야 | 게임 |
| --- | --- |
| 기억 | 패턴 복원, 시퀀스 기억 |
| 추론 | 규칙 분석, 코드 브레이커 |
| 논리 | 조건 배열, 경로 설계 |
| 주의·판단 | 신호 탐색, 룰 스위치 |

모든 게임의 기본 입구를 처음부터 제공한다. 각 게임 안에서는 스테이지를 순차적으로 개방한다. 공통 맵이나 공통 경험치로 다른 게임의 플레이를 강제하지 않는다.

| 모드 | 목적 | 진행·기록 |
| --- | --- | --- |
| 스테이지 | 규칙 학습과 난이도별 도전 | 게임별 진행, 완료, 도움 여부, 개인 성적 |
| 자유 연습 | 원하는 조건 반복, 보충 연습과 복습 | 조건별 연습 기록. 공식 순위와 분리 |
| 공식 챌린지 | 동일 조건에서의 비동기 경쟁 | 로그인 필요. 고정 규칙과 검증된 공식 결과 |

일반 플레이에는 목숨이나 대기 시간을 두지 않는다. 게임 특성상 필요한 기억 자극의 표시 시간·반응 시간은 유지한다. 조작 시간을 줄이는 것만으로 난이도를 올리지 않는다.

## 5. 공식 경쟁 설계안

첫 경쟁 운영은 게임별 주간 챌린지를 기준안으로 한다. 일반 스테이지와 독립된 문제 묶음을 사용한다. 주간 단위, 문제 수, 공식 응시 횟수는 확정 전 검증 항목이다.

- 같은 대회·입력 구분의 참가자에게 동일한 출제 조건과 채점 기준을 적용한다.
- 기본안은 계정당 대회별 공식 응시 1회다. 공식 시작 전에 규칙과 연습 예제를 확인할 수 있다.
- 기록 제출을 원할 때 공식 도전을 시작한다. 가입했다고 자동으로 참가시키지 않는다.
- 공식 정답과 상세 해설은 대회 종료 후 공개한다.
- 제출된 결과의 성립 여부를 검증한다. 비정상 기록은 근거와 처리 이력을 남겨 검토한다.
- 정확도·시도 수·경로 효율 등의 게임별 지표를 먼저 사용하고, 시간은 필요한 종목에 한정한다.
- 반응 속도가 중요한 게임은 터치·마우스·키보드 등 입력 방식에 따른 순위를 구분한다. 혼합 입력과 변경 시의 처리도 상세 설계에 포함한다.
- 동일 기록은 공동 순위로 취급하는 것을 기본안으로 한다.
- 브라우저 이동·중단·통신 장애 시 처리 규칙을 응시 전에 안내한다. 복구를 이용한 추가 열람·추가 시도가 생기지 않도록 검증한다.

공식 결과의 공정성에는 문제 공유, 다중 계정, 자동 입력 등의 위험이 남는다. ‘완전한 부정행위 방지’를 보장하지 않고, 검증 가능한 결과·운영 절차·명확한 제재 근거를 마련한다. 공정성이 해결되지 않은 종목은 순위 공개 완료로 판정하지 않는다.

첫 방문의 주 행동은 게임 체험이다. 시작 전에 능력 검사나 긴 설문을 요구하지 않는다. 추천을 따르지 않아도 모든 게임 입구에 접근할 수 있다. 경쟁과 학습 흐름은 구분하며, 학습 화면에서 다른 사람의 순위를 반복 노출하지 않는다.

## 7. 계정·기록 정책

### 7.1 가입과 복구

- 필수 가입 입력은 ID와 비밀번호다. 공개 닉네임은 자동 부여 후 변경할 수 있다.
- 로그인 ID와 복구 이메일을 공개 순위에 노출하지 않는다.
- 복구 이메일 연결은 선택이다. 이메일 인증 완료 후에만 복구 수단으로 사용한다.
- 복구 이메일이 없는 경우 복구 제한을 짧게 안내한다. 연결하지 않아도 기본 이용을 막지 않는다.
- 비밀번호 재설정 요청은 계정 존재 여부가 불필요하게 드러나지 않게 응답한다.
- 재설정 링크는 제한된 시간에 한 번 사용하고, 재설정 완료 후 기존 로그인 세션을 정리한다.
- 비밀번호 원문을 보관하지 않는다. 로그인·복구의 반복 시도를 제한하고 안전한 전송·저장을 검증한다.
- 이메일 발송과 재설정 동작은 구현 후 실제 수신 환경에서 확인해야 한다. 복구 이메일을 입력받았다는 사실만으로 복구 기능 완료로 판정하지 않는다.

### 7.2 게스트와 계정의 연결

- 게스트 기록은 해당 브라우저에 저장한다. 브라우저 데이터 삭제 시 유실될 수 있음을 기록 화면에 안내한다.
- 새 계정 생성 시 현재 게스트의 스테이지 진행과 학습 기록을 연결한다.
- 기존 계정에 로그인할 때 게스트 기록을 합칠지 안내한다. 다른 사람의 기록이 자동으로 섞이지 않게 한다.
- 병합 시 완료 이력은 합치되, 같은 기록의 중복 합산을 방지한다. 최고 기록은 비교 조건이 일치하는 경우에만 비교한다.
- 게스트 기록은 공식 응시 기록으로 전환하지 않는다.
- 계정 연결 완료를 확인한 뒤 연결 상태를 표시한다. 실패하면 게스트 원본을 보존하고 재시도할 수 있다.
- 서로 다른 기기의 기록 충돌과 삭제·탈퇴 정책은 상세 설계에서 정의하고 검증한다.

## 8. 접근성과 연구소 표현

- 큰 글자, 충분한 대비, 읽기 쉬운 문장, 넉넉한 조작 영역을 기본으로 한다.
- 색상만으로 정답 조건을 구분하지 않는다. 모양·표식·텍스트를 함께 사용한다.
- 효과음·배경음·애니메이션은 조절할 수 있다. 소리만으로 정답 단서를 주지 않는다.
- 드래그가 필요한 게임에는 선택 후 배치 등 대체 조작을 제공한다.
- 키보드 탐색과 포커스를 고려한다. 반응 게임의 키보드 입력은 경쟁 구분에도 반영한다.
- 연령으로 사용자의 실력이나 필요한 난이도를 단정하지 않는다. 실명·생년월일 수집을 기본 전제로 삼지 않는다.
- 학습 모드의 속도 조절은 허용하되, 기록에는 출제 조건을 남긴다. 공식 경쟁은 공지한 동일 조건을 사용한다.
- 번쩍이는 효과·빠른 배경 움직임·상시 장식 애니메이션을 문제 풀이의 필수 요소로 사용하지 않는다.

## 9. 콘텐츠 제작·검수 기준

각 스테이지는 학습 목표, 필요한 선수 규칙, 출제 조건, 통과 기준, 정답 판정, 힌트, 해설, 동급 보충 문제, 난이도 근거를 갖춘다.

1. 의도한 규칙이 설명과 일치하는가?
2. 조건을 만족하는 답이 존재하는가? 정답을 하나로 의도했다면 유일한가?
3. 복수 해답을 허용한 퍼즐은 모든 유효 해답을 인정하는가?
4. 힌트와 해설이 실제 문제·정답과 일치하는가?
5. 기억·주의 문제의 표시 시간과 입력 조건이 기기에서 재현되는가?
6. 색상·소리·드래그에 의존하는 장벽이 없는가?
7. 이전 스테이지에서 배우지 않은 규칙이 설명 없이 등장하지 않는가?
8. 문제를 바꾸거나 철회할 때 이전 기록과 공식 순위의 처리 기준이 있는가?

AI가 작성한 문제·해설도 동일한 검수를 거친다. 자동 생성 가능성은 구현·검증 전의 설계 가정이며, 생성량을 검수 완료 콘텐츠 수로 세지 않는다.

## 10. 출시 완료 기준

| 영역 | 확인할 결과 |
| --- | --- |
| 게임 8종 | 안내·플레이·판정·결과·재도전이 연결되고 규칙대로 작동 |
| 학습 도구 | 목표·힌트·해설·보충 문제의 일치, 도움 사용 기록, 조건별 비교 |
| 콘텐츠 | 출시 문제의 성립·정답·해설 검수 및 난이도 점검 |
| 계정 | 가입·로그인·선택 이메일 인증·비밀번호 재설정의 실제 동작 |
| 기록 | 새로고침·기기 변경·게스트 병합·통신 실패에서 보존 정책 충족 |
| 경쟁 | 동일 조건·채점·응시 제한·결과 검증·중단 정책 확인 |
| 접근성 | 모바일·PC, 큰 글자, 색상 외 구분, 대체 조작 점검 |

| 개인정보 | 수집 목적·공개 범위·보관·삭제·탈퇴 정책과 실제 동작 일치 |

학습 지표는 동일 조건의 새 문제 정확도와 도움 의존도의 변화로 관찰한다. 재미·사용성은 첫 게임 완료, 게임별 이탈 구간, 자발적 재도전, 재방문으로 관찰한다. 구체적인 수치 목표는 초기 사용자 검증 이후 정한다. 제로 오류나 인지 능력 향상 보장 같은 선언으로 완료 기준을 대신하지 않는다.
