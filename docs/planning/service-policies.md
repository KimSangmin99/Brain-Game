# 계정·기록·경쟁 정책

상태: v0.2 구현 기본값. 외부 서비스 계약·법률 검토 완료를 뜻하지 않는다.

## 1. 계정

- 로그인 ID: 영문 소문자·숫자·밑줄 4~20자. 입력 시 앞뒤 공백 제거·소문자 정규화. 생성 후 변경 불가. 탈퇴한 ID는 재사용하지 않고 원문 대신 재사용 방지용 식별 해시만 남긴다.
- 비밀번호: 15~128자, 공백·한글 허용, 복잡도 조합 강제 없음. 붙여넣기·비밀번호 관리자 허용. 흔한 유출 비밀번호를 차단하되 외부 서비스에 원문을 보내지 않는다.
- 닉네임: 자동 부여, 한글·영문·숫자·공백 2~16자. 공개 표시용이며 ID와 별개. 중복 허용, 공식 목록에서 공개 랜덤 태그를 붙여 구분. 부적절한 이름은 운영자가 사유를 남겨 변경.
- 가입 시 이메일은 요구하지 않는다. 이용약관·개인정보 안내 버전을 기록한다. 실명·생년월일을 가입 항목에 추가하지 않는다.
- 기본 세션은 미사용 7일 또는 발급 30일 후 종료. 재설정·로그인 중 비밀번호 변경·전체 로그아웃·탈퇴 시 모든 세션 폐기. 이메일 변경·탈퇴는 비밀번호 재확인 필요.
- 로그인 초기 제한: 계정 ID당 5회 실패/15분, IP당 30회 실패/15분. 영구 잠금 없이 잠시 후 재시도 안내. 분산 IP 공격·공유망 오탐을 검증해 조정.

## 2. 선택 복구 이메일

- 이메일은 앞뒤 공백 제거, 도메인 소문자화. 점·플러스 주소를 임의로 제거하지 않는다. 인증된 이메일은 한 계정에만 연결한다.
- 연결: 로그인·비밀번호 재확인 → 주소 제출 → 30분 유효 단일 인증 링크 발송 → 링크 확인 → 연결 완료. 미인증 주소로 복구 불가.
- 주소 변경 중에는 기존 인증 주소가 유지된다. 새 주소 인증 완료 시 교체하고 이전 주소에 변경 사실을 통지한다. 실제 알림 발송은 구현 단계 기능이며 현재 발송하지 않는다.
- 연결 해제: 비밀번호 재확인, 복구 제한 안내 후 해제. 이전 주소에 알림.
- 복구 요청: ID와 이메일 입력. 일치·계정 존재 여부와 무관하게 ‘입력한 정보가 일치하면 안내 메일을 보냈습니다’ 응답.
- 재설정 링크는 15분 유효, 1회 사용. 새 링크가 발급되면 이전 재설정 링크 폐기. 완료 시 모든 세션 폐기 후 다시 로그인.
- 요청 제한: 계정·주소당 3회/시간, IP당 10회/시간, 재발송 최소 60초. 제한된 요청도 계정 존재 여부를 노출하지 않는 응답 사용.
- 이메일 미연결·미인증 계정은 자동 복구 불가. 운영자가 진행도·닉네임만으로 소유자를 판단해 비밀번호를 바꾸지 않는다.
- ID 분실: 이메일만 입력해 연결된 ID를 그 이메일로 안내하는 경로 제공. 화면에는 존재 여부를 표시하지 않으며 같은 제한 적용.
- 메일 발송 실패는 내부 재시도 큐에 기록하고 사용자에게 재요청 경로를 제공한다. 인증·복구 링크 원문은 로그에 남기지 않는다.

## 3. 기록과 병합

기록 원본은 attemptId별 불변 결과다. 집계는 원본에서 계산한다. 회원은 서버, 게스트는 브라우저 저장소가 기준이다. 게스트에서 가져온 결과는 imported로 표시해 공식 기록과 구분한다.

### 병합 순서

1. 가입 또는 로그인 후 현재 브라우저의 게스트 기록 건수와 계정의 진행 요약을 표시한다.
2. 새 가입은 연결 동의를 가입 흐름에서 받고, 기존 계정은 ‘합치기 / 나중에’를 선택한다.
3. 파일 구조·게임 ID·버전·범위·용량을 검증한다. 1회 최대 1000건씩 나눠 전송한다.
4. guestProfileId+attemptId를 중복 방지 키로 등록하고 트랜잭션으로 기록·집계·병합 영수증을 저장한다.
5. 완료 단계는 합집합, 독립 성취는 조건 일치 시 합집합, 최고 점수는 동일 비교 키에서 최댓값. 학습 횟수는 중복 원본 제거 후 계산.
6. 서버 영수증 확인 후 로컬 기록을 ‘이 계정에 연결됨’으로 표시한다. 로컬 원본은 7일간 복구용으로 보존하고 자동 삭제한다. 실패 시 삭제하지 않는다.
7. 다른 계정에 이미 연결한 게스트 기록은 재병합하지 않는다. 새 게스트 프로필로 분리한다.

동시 기기 저장은 마지막 쓰기로 진행도를 덮어쓰지 않는다. 완료 집합은 늘리는 방향으로 병합하고, 프로필 설정 변경은 버전이 다르면 최신값을 다시 확인한다. 공식 활성 세션은 계정당 1개, 일반 세션은 여러 개 허용한다.

비교 키: gameId + mode + rulesVersion + content difficulty + timing preset + assistance + interruption/repeat flags. 공식은 eventId + inputClass를 추가. 알려진 버전 오류가 있는 기록은 비교 제외 사유를 표시하고 원본은 감사 목적 범위에서 보존한다.

## 4. 공식 챌린지

- 각 게임별 주 1개. 한국 시간 월요일 00:00~다음 월요일 00:00, 종료 시각은 미포함. 저장은 UTC, 표시와 주 경계는 Asia/Seoul.
- 계정당 대회별 응시 1회. search·switch는 입력 분류별로 추가 응시를 주지 않고 처음 고른 분류에만 응시한다.
- 시작 API에서 참가권과 첫 문항을 원자적으로 만든다. 첫 문항 응답을 사용자가 못 받았어도 같은 요청키로 재조회하며 새 응시를 만들지 않는다.
- 시작 후 최대 15분, 개별 문항 시간 제한과 대회 종료 중 가장 이른 시각에 종료. 남은 문항 0점. 종료 직전 시작 시 이용 가능한 시간이 짧다는 안내를 제공한다.
- 문항마다 순서대로 제출. 서버가 다음 문항을 허가한다. 완료한 문항 답 변경 금지. 문항당 제출은 원자적으로 한 번 접수.
- 순위는 서버 재계산 결과만 등록한다. 브라우저가 전송한 최종 점수·완료 플래그를 신뢰하지 않는다.
- 규칙 버전과 문제 묶음은 대회 시작 후 고정. 정답 오류 발견 시 해당 대회 전체 취소, 공지, 별도 새 대회 ID로 재개최. 이전 응시 횟수를 새 대회에 적용하지 않는다.
- 기록 의심만으로 즉시 계정 차단하지 않는다. 순위 검토 중 표시, 검토 근거·결과·이의 제기 경로를 남긴다.
- 동점은 공동 순위. 별도 통합 순위 없음. 완료된 유효 공식 응시만 등재하며 0점도 유효 완료일 수 있다.

### 중단 처리

| 상황 | 일반 학습 | 공식 |
| --- | --- | --- |
| 답 전송 응답 유실 | 같은 요청 재시도, 접수 결과 재조회 | 같은 문항·요청키로 재조회. 새 답으로 덮어쓰기 불가 |
| 통신 단절 | 로컬 답 보존. 회원 서버 저장 완료 전 대기 표시 | 서버 시한은 계속 진행. 재연결 시 접수 상태 조회, 시한 이후 도착 답은 인정하지 않음 |
| 탭 숨김·새로고침 | 기억·주의 현재 문항 교체; 퍼즐은 초안 복원 | pattern·sequence·search·switch는 해당 문항 무효 0점, 다음 문항부터 계속. rule·code·arrangement·route는 동일 문항 복귀, 타이머 계속 |
| 공식 응시 나가기 확정 | 해당 없음 | 현재·나머지 문항 0점으로 종료, 재응시 불가 |
| 서버 장애가 확인됨 | 재시도·기록 보존 | 영향을 받은 대회 전체 취소 후 새 대회로 재개최. 개별 재응시로 동일 문제 재노출 금지 |
| 입력 방식 변경 | 새 조건으로 기록 | search·switch 해당 응시는 연습 기록으로 전환하고 공식 순위 제외, 참가권은 사용 상태 유지 |

숨김·입력 방식은 브라우저 관찰만으로 완벽히 검증할 수 없다. 클라이언트 조작·캡처·다중 계정의 잔여 위험을 운영 기준에 남긴다. 공식 결과를 금전 보상·자격 판정에 사용하지 않는다.

## 5. 개인정보·운영 기본안

- 공개: 닉네임·랜덤 공개 태그·공식 점수·대회 순위. 비공개: ID·이메일·세션·개인 학습 상세·기기 식별정보.
- 계정 탈퇴: 비밀번호 재확인 후 세션 즉시 종료, 공개 순위 즉시 비식별화, 개인정보와 개인 기록은 운영 DB에서 7일 이내 삭제. 현재 구현은 비밀번호·ID·동의 재확인 후 트랜잭션으로 즉시 삭제하며 별도 취소 유예는 없다. 법적 보관이 실제 필요한 항목은 목적·기간을 별도 고지한다.
- 삭제 확인·ID 재사용 방지에는 무작위 계정 식별자·정규화 ID의 SHA-256·무작위 삭제 확인값의 해시·삭제 시각만 비공개 원장에 남긴다. 최소 원장은 ID 재사용 방지를 위해 유지한다. 로그인 ID 해시를 익명 자료로 간주하지 않는다.
- 백업은 암호화·접근 제한하고 30일 순환 보관. 복구 시 삭제 목록을 다시 적용해 탈퇴 계정을 되살리지 않는다.
- 원시 플레이 이벤트는 90일, 비교용 결과는 계정 유지 동안, 보안·운영 감사 로그는 90일을 초기 보관 기본값으로 한다. 계정 삭제 시 연결 정보를 제거한다. 법률 검토에 따라 실제 고지와 일치시킨다.
- 문의는 로그인 사용자에게 접수 번호를 제공하고, 게스트는 선택 연락 이메일로 접수한다. 실제 운영 연락처는 공개 배포 전 확정.
- 오류 문제 비공개, 대회 취소, 닉네임 조치, 기록 검토는 운영자 권한과 감사 이력을 요구한다. 개인정보·비밀번호·복구 토큰을 감사 로그에 남기지 않는다.

2026-11-13 구현 현황: 비밀번호 변경·전체 로그아웃·운영 DB 즉시 탈퇴와 삭제 확인 복구를 제공한다. 백업의 30일 보관·최신 삭제 원장 별도 보존·복원 재적용은 운영 검증 전 설계값이다. 이메일 복구는 미구현이며 [실제 구현 계약](../accounts/security.md)을 따른다.
